# smart.teaching

صفحة ويب للمعلم **محمد صالح العمير الأسمري** — مدرسة العماير الابتدائية والمتوسطة والثانوية — الفصل الدراسي الأول 1448هـ.

## المحتويات
- **جدول المعلم**: جدول الحصص الأسبوعي (الأحد–الخميس) مع عرض درس الأسبوع المحدد داخل كل حصة وفق توزيع المنهج.
- **توزيع المنهج**: تبويب لكل فصل (4ب، 5ب، 6ب، 1ث) يعرض دروس الأسابيع 1–19 مع التواريخ الهجرية والميلادية.
- **الكشوف الأسبوعية**: كشف درجات لكل فصل بالمعايير: الحضور، الواجب، المشاركة، الانضباط، القرآن حفظ، القرآن تلاوة (كل معيار من 5). تلوين تلقائي (أحمر→أخضر، 6 ذهبي، 7 ماسي)، رمز غياب «غ»، فرز بالأعمدة، ومتوسط كل الأسابيع من 100.

## التقنية
- ملف واحد `index.html` (HTML/CSS/JS خالص، RTL).
- قاعدة بيانات **Supabase** (جدول `marks`) لحفظ الدرجات سحابياً لتظهر من أي جهاز.
- صفحة دخول بكلمة مرور.

## التشغيل
افتح `index.html` مباشرة في المتصفح أو استضفه كموقع ثابت (GitHub Pages / أي استضافة).
